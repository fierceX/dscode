面向终端，也面向系统的 AI agent runtime

mink 用 Rust 实现，既适合在终端中直接工作，也适合嵌入到服务端、桌面端或内部工具中。

核心特点

统一运行时、长任务可控，以及更可靠的编辑与状态管理。

Runtime

可嵌入的运行时内核

CLI、REPL、TUI、Python SDK 和 Rust 嵌入共享同一个 runtime，不需要为不同入口维护多套语义。

Context

长上下文与长任务可控

压缩、活跃投影和持久化会话共同工作，让上下文不会无限膨胀，也让长任务可以持续推进。

Reliability

编辑与状态管理更可靠

Anchored Edit、artifact 回读、会话状态和恢复机制共同约束修改与回读路径，不把正确性交给运气。

快速开始

根据你的使用方式，从终端、Python SDK 或 Rust 嵌入开始。

直接在终端中运行

适合在本地项目里直接工作。可以进入 REPL，也可以使用 Full TUI 或 Inline TUI。

  • 默认入口
  • 支持继续最近会话
  • 支持 REPL、Full TUI、Inline TUI
Terminal Rust 1.94+ 
# 编译
cargo build --release

# REPL
$ ./target/release/mink -m flash -i

# Full TUI
$ ./target/release/mink -m flash --tui

# Inline TUI
$ ./target/release/mink -m flash --tui=inline

# 恢复最近会话
$ ./target/release/mink -m flash --continue -i

把 agent 接进脚本或服务

适合用 Python 调用 mink，让它成为工作流或服务逻辑的一部分。

  • 适合脚本集成与自动化
  • 不只是包装 CLI
  • 适合已有 Python 系统接入
Python SDK pip 
# 安装
pip install mink-agent

# 最小示例
from mink_agent import Agent

agent = Agent(
    model="flash",
    provider="deepseek",
)

result = agent.run("scan this repo and summarize")
print(result.text)

直接嵌入到 Rust 系统中

如果你希望把 agent 作为系统能力而不是外部进程使用，可以直接使用 mink::runtime。

  • 适合服务端、桌面端或内部工具
  • 与 CLI 共享同一套运行时语义
  • 不需要维护独立 agent 内核
Rust Embed cargo 
# Cargo.toml
mink = { package = "mink-core", version = "0.2.0", default-features = false, features = ["runtime"] }

# 最小示例
use mink::runtime::AgentRuntime;

let runtime = AgentRuntime::start(options).await?;
let result = runtime.run_turn("explain this project").await?;
println!("{}", result.text());
runtime.shutdown().await?;
